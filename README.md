# Mehmet Akif Duran — Interactive Portfolio

A full-screen illustrated portfolio room built for GitHub Pages, with animated loading, ambient dust and light, a smooth day/night transition, a framed Türkiye panorama, softly glowing interactive objects, horizontal mobile exploration, hobby objects, and sliding content panels.

## Publish

1. Upload everything in this folder to the root of your `mehmetakifdurann.github.io` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Open `https://mehmetakifdurann.github.io/` after GitHub finishes publishing.

No build command, package installation, or environment variables are required.

## Customize

- Content is stored in `script.js`.
- Room styling is in `styles.css`.
- Portfolio images and the downloadable CV are in `assets/`.
